# NEXUS STRIKE

Unity로 만든 **5v5 하이퍼 히어로 슈터**입니다. 역할 고정(탱커 1 / 딜러 2 / 힐러 2), 화물 호위 모드, 궁극기 게이지, 방벽, 스킬 쿨다운, 봇 AI 등 이 장르의 핵심 시스템을 구현했습니다.

> 영웅, 맵, 이름은 모두 **오리지널**입니다. 기존 상용 게임의 캐릭터나 에셋, 상표는 사용하지 않았습니다.

## 실행 방법

에셋 파일(씬, 프리팹, 머티리얼, 사운드)이 하나도 필요 없습니다. 맵, 캐릭터, 이펙트, 효과음, UI는 전부 **코드로 런타임에 생성**됩니다.

**방법 A: 이 폴더를 바로 열기**
1. Unity Hub → **Add project from disk** → `NexusStrike` 폴더를 선택합니다.
2. Unity 2021.3 LTS 이상(2022.3 LTS, Unity 6 포함)으로 엽니다. 버전이 다르면 업그레이드를 허용하면 됩니다.
3. 아무 씬(빈 씬도 가능)에서 **Play**를 누릅니다.

**방법 B: 기존 프로젝트에 넣기**
1. `Assets/NexusStrike` 폴더를 내 프로젝트의 `Assets/`에 복사합니다. (Built-in Render Pipeline 권장)
2. 아무 씬에서 **Play**를 누릅니다.

입력은 기존 Input Manager와 새 Input System 패키지를 모두 지원합니다. `Active Input Handling` 설정에 맞춰 자동으로 동작합니다.

빌드할 때는 `File → Build Settings`에 아무 씬이나 하나 추가하면 됩니다. 게임은 `RuntimeInitializeOnLoadMethod`로 자동 시작됩니다.

## 게임 시스템

- **화물 호위(PORT SOLACE 맵)**: 공격팀이 화물 근처에 있으면 화물이 전진하고, 수비팀이 함께 있으면 정지(경합)합니다. 아무도 밀지 않으면 10초 뒤 뒤로 밀려납니다.
- **체크포인트 2개**: 도달할 때마다 시간이 추가되고, 양 팀 스폰 지점이 앞으로 이동합니다.
- **연장전**: 시간이 끝나도 공격팀이 화물에 붙어 있으면 연장전이 이어집니다.
- **준비 시간 15초**: 그동안 공격팀은 스폰룸에 묶여 있습니다.
- **체력 체계**: 추가 체력 → 보호막(자동 재생) → 방어구(피해 30% 경감) → 생명력 순서로 깎입니다.
- **궁극기 게이지**: 피해량, 치유량, 시간 경과로 충전됩니다. 아군이 궁극기를 쓰면 알림이 뜹니다.
- **상태이상**: 기절, 속박, 감속, 넉백, 피해 감소, 이동속도 증가.
- **기타**: 체력팩(소/대), 스폰룸 회복, 리스폰 10초, 킬캠(사망 시 시점), 킬피드, 처치·도움 표시, 히트마커/헤드샷, 피격 방향 표시, 점수판.
- **봇 AI**: 쉬움/보통/어려움 난이도. 역할에 따라 위치를 잡고(탱커는 앞, 힐러는 뒤), 화물을 밀거나 막습니다. 힐러는 다친 아군을 우선 치유하고, 체력이 낮으면 체력팩으로 갑니다. 투사체 영웅은 예측 사격과 스플래시를 노린 발밑 조준을 하고, 상황에 맞춰 스킬과 궁극기를 씁니다.
- **런타임 내비게이션**: NavMesh 굽기 없이 맵을 격자로 샘플링해 다층(경사로, 고지대) 보행 그래프를 만들고 A*로 길을 찾습니다.

## 코드 구조

```
Assets/NexusStrike/Scripts/
  Core/      GameBootstrap, GameManager(매치 흐름), Combatant(체력/상태), HeroMotor(이동), PlayerBrain, GameInput
  Heroes/    HeroRoster(영웅 데이터), HeroKit(무기/스킬 베이스), TankKits, DamageKits, SupportKits, HeroModel
  Gameplay/  CombatUtil(히트스캔/폭발), Projectile, Barrier, Zones(장판/포탑), Payload, HealthPack
  AI/        NavGraph(A*), BotBrain
  World/     MapBuilder(맵 생성), MaterialLib
  FX/        Fx(트레이서/폭발), Sfx(절차적 효과음 합성)
  UI/        Hud(메뉴, 영웅 선택, 전투 HUD, 점수판)
```

**새 영웅 추가하기**
1. `HeroKit`을 상속한 클래스를 만들고 `Setup`, `BuildWeapon`, `HandleFire`, `UseAbility1/2`, `UseUltimate`, `BotAbilities`를 구현합니다.
2. `HeroRoster`에 `HeroDefinition`을 하나 추가합니다.
3. `HeroModel.Construct`의 `switch`에 외형을 추가합니다.

팀 구성, 선택 화면, AI는 새 영웅을 자동으로 사용합니다.
